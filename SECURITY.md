# Security Policy

This is my personal portfolio website — a static site with no backend, database, or user data.

## Found a security issue?

Please report it privately here: [Report a vulnerability](https://github.com/azmainemahatab/azmainemahatab.github.io/security/advisories/new)

I'll take a look and respond as soon as I can. Please avoid opening a public issue for anything sensitive.

Thanks for helping keep this safe!
